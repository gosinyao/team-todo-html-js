# Проект: Список задач (Командная работа)

## Описание
Веб-приложение для управления повседневными задачами. Данные сохраняются в браузере, не теряются при перезагрузке.

## Технологии
- HTML
- CSS
- JavaScript
- localStorage

## Распределение ролей
1. UI: верстка и стилизация страницы
2. Frontend: логика добавления, завершения и удаления задач
3. Backend: локальное хранение данных
4. Тестирование: проверка функций и документация

## Функции
- Добавление новых задач
- Отметка выполненных задач
- Удаление ненужных задач
- Сохранение данных после перезагрузки# team-todo-html-js
Командный проект веб-приложения «Список задач». Стек технологий: HTML + CSS + JavaScript + localStorage. Реализованы добавление, отметка выполнения, удаление задач и сохранение данных.
